# IRO – Issues Reporting Outlet

A web-based system for reporting and tracking issues concerning AAUA students and indigenes of Akungba, Iwaro, Etioro, Ayegunle and nearby communities.

Course project for **CSC426** (Weekly Dev – Weekend 3), submitted to Dr. O. O. Ajayi.

## Features (prototype)
- Report an issue by category, with an anonymous option and an urgent flag
- Receive an Issue ID and track status (Pending, In Progress, Resolved)
- Public list of resolved issues
- Admin panel to filter issues, change status and respond

## Run it
Open `index.html` in any browser. No installation needed.
Demo admin password: `admin123`
Data is saved in the browser's local storage (prototype only).
